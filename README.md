# EcoMissão Online — Guardiões da Paisagem

Jogo educativo de restauração ecológica desenvolvido em **HTML, CSS e JavaScript**. Joga-se diretamente no navegador, em computadores e celulares. Não há cadastro e o progresso fica salvo no navegador utilizado.

## Publicar no GitHub Pages

**Sugestão: publicar como repositório independente `ecomissao-online`, sem substituir seu site existente.**

1. Na conta `dombroskilia`, crie um repositório **público** chamado `ecomissao-online`.
2. Envie **index.html, style.css e game.js** para a raiz do repositório, não somente o ZIP.
3. Abra **Settings → Pages**.
4. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/ (root)`, e clique **Save**.
6. Após a publicação, abra `https://dombroskilia.github.io/ecomissao-online/`.

O endereço acima é **previsto**, e só funcionará após a publicação. A ativação pode levar alguns minutos.

## Abrir no computador antes de publicar

Abra `index.html` no navegador. O jogo funciona sem servidor, sem Python e sem bibliotecas externas.

## Controles

- Clique em uma das seis intervenções e depois na parcela do mapa.
- Clique em **Avançar período** para simular o tempo e receber recursos.
- No teclado: 1 a 6 selecionam as ações, N avança período e H abre as instruções.
- No celular: toque nos botões e nas parcelas.
- O jogo salva automaticamente a partida no armazenamento local do navegador. Use **Recomeçar** para uma nova tentativa.

## Nota científica e pedagógica

Esta é uma **simulação educativa fictícia**. Os indicadores e taxas foram simplificados para a mecânica de jogo, não foram validados cientificamente e não devem ser utilizados como previsões, recomendações de manejo ou diagnóstico ambiental.

## Sobre o código

Uma aplicação web estática precisa enviar HTML/CSS/JavaScript ao navegador. Portanto, o código poderá ser visualizado pelos visitantes. Esta versão **não inclui o código privado do AntMorph-AI**.
